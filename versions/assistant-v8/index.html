Assistant — discovery

The FoodBridge Assistant: a distributor sets up his store in a WhatsApp-style chat, one question at a time — products read from any file, the store summed up, then the request goes to the FoodBridge team. assistant-v8 — for review

The assistant ↗Its own page, opens on “hi”. On a computer: WhatsApp Web: chats, the conversation, your store setup. As on a phone ↗The contacts card is the address book. Best in a phone-sized window. In the Control Tower ↗The same chat as the tower's panel, over the Vasu Foods board. What reached FoodBridge ↗The builds from Create my store.

Serve over HTTP (a service worker stands in for the bridge and for Claude; it does not run from file://): python3 -m http.server 8790 --directory modules/assistant/discovery. Nothing leaves the browser. ?vasu=<url> points the tower at another copy of mock-platform v7 (default: the published one). Start fresh: the chat's ⋯ → Start again.

The question tree (screens/chat/onboard.js)

One question at a time. v6 changes marked ●. Every answer lands in the store's state (screens/store/model.js), so the Excel the team receives carries exactly what he said.
